# Comprautos — novo layout (proposta 2)

Protótipo navegável de um novo front para o Comprautos, mantendo a logo atual. São três telas: início, busca e página do veículo.

- `index.html`: início com busca (comprar ou vender pela placa), ofertas abaixo da FIPE, seção para lojistas e proteção veicular.
- `busca.html`: resultados com filtros, selo de comparação com a FIPE e parcela estimada em cada anúncio.
- `veiculo.html`: galeria, comparação com a FIPE e com a média do Comprautos, chat com a loja e simulador de financiamento.

Anúncios, preços, cidades e lojas são exemplos. As fotos vêm do estoque de teste do site atual. O simulador usa uma taxa de exemplo de 1,69% a.m. e não representa oferta de crédito.

O desenho original está no canvas do claude.ai; estas páginas são a versão em HTML estático para apresentação.
